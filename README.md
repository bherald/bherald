# William Paul Herald

I have spent more than 40 years building, testing and improving software and systems, from BASIC, dBase, FoxPro and SQL to web applications and local AI.

I am building a **Personal Life Operating System** to bring documents, research, workflows and personal information together, with people reviewing consequential decisions. The private system stays private. I share useful parts as MIT-licensed projects that others can inspect and run.

## What you can try

- **[Personal Life OS Core v2.1](https://github.com/bherald/personal-life-os-core)** brings documents, research, workflows and review into one application. Start with the [research walkthrough](https://github.com/bherald/personal-life-os-core/blob/main/docs/research-workbench.md) and fictional nightly examples. Installation and AI routes need your own configuration.
- **[Photo Knowledge](https://github.com/bherald/photo-knowledge)** shows how reviewed names, face rectangles, captions and keywords can travel with a picture. Try the XMP sidecar generator or inspect the embedded JPEGs. Example names are fictional; the tool does not identify people.
- **[Cyber Review Workbench](https://github.com/bherald/cyber-review-workbench)** runs a small local security-check example, saves its evidence and compares it with a control. It needs only Python's standard library. Passing the example leaves human review open; it does not certify a system.
- **[VISOR](https://github.com/bherald/AI-CLI-MANAGER-VISOR)** supervises independent Codex and Claude Code terminals, with exact-session resume, window controls and messages between sessions. It is a beta for Windows, Linux/X11 and macOS. Mac builds pass hosted checks on Apple silicon and Intel; interactive Mac desktop testing is still unverified.
